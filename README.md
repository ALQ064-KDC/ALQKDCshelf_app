# 棚番・商品コード検索アプリ

スマホのカメラでJANコードを読み取ると、棚番と自社商品コードを即座に表示するアプリです。
前回の「商品スキャン記録アプリ」とは別の独立したアプリです(書き込みではなく検索)。

構成:
```
[スマホのブラウザ]
  → GitHub Pages上の index.html (カメラ・バーコード認識)
  → Google Apps Script Web App (検索)
  → Google スプレッドシートの「マスタ」タブ
```

## 1. マスタスプレッドシートの準備

1. 新しいGoogleスプレッドシートを作成する
2. シート(タブ)の名前を「マスタ」にする
3. 1行目にヘッダーを入力する:
   - A1: `JANコード`
   - B1: `ケースJANコード`
   - C1: `棚番1`
   - D1: `棚番2`
   - E1: `自社商品コード`
4. 2行目以降に、わかっている範囲でデータを入力していく(後から追加・修正してOK)
   - ケースJANコードや棚番2が無い商品は、その列を空欄のままでOK
   - スキャンしたコードが「JANコード」列・「ケースJANコード」列のどちらと一致しても検索できます

## 2. Apps Scriptの準備

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く
2. デフォルトのコードを削除し、`Code.gs` の内容を貼り付けて保存
3. 「デプロイ」→「新しいデプロイ」
   - 種類: **ウェブアプリ**
   - 実行するユーザー: **自分**
   - アクセスできるユーザー: **全員**
4. デプロイ後に表示される「ウェブアプリのURL」をコピーしておく

   ※マスタのデータ自体はスプレッドシートを直接編集するだけで反映されます。
   再デプロイが必要なのは `Code.gs` のコードを変更したときだけです。

## 3. GitHub Pagesの準備

前回の「商品スキャン記録アプリ」と同じ手順です。
1. 新しいリポジトリを作成する(例: `shelf-lookup-app`)
2. `index.html` をアップロード
3. 「Settings」→「ページ」で `Deploy from a branch` / `main` / `/(root)` を設定して保存
4. 公開されたURL(`https://ユーザー名.github.io/リポジトリ名/`)をスマホで開く

## 4. 初期設定

1. スマホでURLを開き、カメラ許可を求められたら許可する
2. 右上「検索先の設定」から、手順2でコピーしたApps ScriptのURLを貼り付けて保存

## 5. 使い方

JANコードをカメラに映すだけです。マスタに一致するデータがあれば、棚番と自社商品コードが自動で表示されます。見つからない場合はその旨が表示されます。

検索結果の下にある「メモを送信」欄に文字を入力して送信すると、その時点で表示していたJANコードと一緒に、スプレッドシートの「メモログ」タブ(自動作成)に追記されます。

## 補足

- 前回のスキャン記録アプリと同じApps Scriptプロジェクト・同じスプレッドシートを使い回すことも可能です。その場合は既存のスプレッドシートに新しいタブ「マスタ」を追加し、`Code.gs` に今回の `doGet` 関数を追記してください(`doPost` と `doGet` は共存できます)。
